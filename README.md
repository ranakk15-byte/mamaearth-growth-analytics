# Mamaearth Growth Analytics | Returns Intelligence

## Overview

An end-to-end analytics project designed to uncover order return patterns, investigate revenue discrepancies, and transform raw transactional data into actionable business intelligence.

The project integrates SQL, Python, and Generative AI into a connected pipeline, ensuring that business recommendations are grounded in computed analytical results.

## Project Architecture

**01 — SQL Database**
- Relational data modelling using SQLite.
- Data ingestion and validation.
- Business-focused SQL reporting.

**02 — Python Analytics**
- Data cleaning and quality checks.
- Exploratory data analysis and revenue reconciliation.
- Return-rate analysis across payment methods, cities, and products.
- Statistical testing, outlier detection, and visualisation.

**03 — Generative AI**
- Automated generation of executive summaries.
- Evidence-based business recommendations.
- Numerical validation against verified analytical findings.
- Offline fallback for reliable execution without an API connection.

## Technology Stack

Python | SQLite | SQL | Pandas | NumPy | Matplotlib | Google Gemini API | JSON | GitHub

## Business Objective

Identify where returns are concentrated, determine how data quality affects business metrics, evaluate revenue trends, and provide operations and finance teams with evidence-based recommendations.

## Pipeline

Raw CSV Data → SQLite → SQL Reports → Python Analysis → Verified Findings (JSON) → GenAI Narrative → Business Recommendations

## Key Deliverables

- Relational database and SQL business reports.
- Reproducible Python analysis scripts.
- Return-rate and revenue-trend visualisations.
- Machine-readable analytical findings.
- AI-generated executive narrative with numerical validation.
